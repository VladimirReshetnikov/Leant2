# Leant2: Native Dependent-Type and Behavioral Program Synthesis in Lean

Technical architecture and algorithm design, prepared for Vladimir Reshetnikov,
September 17, 2026.

Start with **article/Leant2.pdf**. The complete LaTeX source is in `article/`.
The architecture is a proposal; the accompanying Lean files are deliberately
small checked experiments, not a complete Leant2 implementation.

## Contents

- `article/Leant2.pdf`: the complete article, including source provenance,
  formal contracts, algorithms, trust boundaries, evaluation plan, experimental
  findings, and the full native prototype listing.
- `article/Leant2.tex`: master source; the other `.tex` files are included chapters
  and the bibliography.
- `prototype/NativeCore.lean`: exact accepted native synthesis experiment.
- `prototype/Certificates.lean`: exact accepted, manually authored reference
  certificates for recursive construction, non-inhabitation, and pruning.
- `prototype/lean-toolchain`: selects Lean 4.34.0.
- `prototype/recheck.py`: optional standard-library Python client for fresh remote
  checks. It preserves imports and saves the raw response. It is a transport and
  diagnostic helper, not an independent Lean kernel.
- `experiments/*_receipt.json`: structured transcriptions of actual successful
  remote responses, including request IDs, source-echo qualification, axioms,
  and executor identifiers.
- `experiments/behavior_lab.py`: finite behavioral mechanisms and five unit tests.
- `experiments/behavior_results.json`: generated results from that laboratory.
- `experiments/HISTORY.md`: actual failed preliminary runs and corrections.
- `Makefile`: document build and local test targets.

## Build the article

A TeX installation with XeLaTeX and the packages named in the master source is
required. The document uses the Latin Modern font files supplied by TeX. It
prefers DejaVu Sans Mono when available and otherwise falls back to Latin Modern
Mono. Font binaries are not included.

From this directory:

```sh
make pdf
```

Or run `xelatex -interaction=nonstopmode -halt-on-error Leant2.tex` three times
from `article/`. The extra passes stabilize the contents and cross-references.
No bibliography processor or external figure generator is required.

## Check the Lean sources locally

With elan/the specified toolchain already available, from `prototype/`:

```sh
lean NativeCore.lean
lean Certificates.lean
```

Both files import only `Lean`. Inspect the printed axiom inventories, not only
the process exit code. `NativeCore.lean` includes two expected-failure controls;
those are successful tests when the attempted synthesis fails as specified.

The checked native file contains eleven whole-goal synthesized definitions and
one manually chosen recursion template with synthesized branches. Two `rfl`
theorems check selected output data, and two controls test bounded-search
failure. Of fourteen named axiom reports, only `vectorHead` uses an axiom:
`propext`. No final audited declaration uses `sorryAx`.

The reference file's pruning theorem uses `propext` and `Quot.sound`; its other
three named declarations have empty axiom reports. That file was written by
hand, not generated by the prototype.

## Optional remote check

Python 3.9+ and network access are required:

```sh
python prototype/recheck.py prototype/NativeCore.lean
python prototype/recheck.py prototype/Certificates.lean
```

The service may change its environment availability. The actual checks recorded
here used AXLE's `lean-4.34.0` environment through Wolfram HTTP calls, not this
Python client's network path. The local container had no Lean installation or
usable network path. The processed source echo differed by exactly one appended
line feed; imports were preserved. Successful receipts are summaries rather
than raw HTTP captures, and no independent local replay was performed.

## Reproduce the finite behavioral laboratory

```sh
python experiments/behavior_lab.py
```

This uses only Python's standard library. It enumerates 1,875 small list terms,
checks their affine lengths on 49 input pairs, and exercises reversible parking,
completion/refutation distinctions, unknown handling, and correlated choice.
It is NOT a full Lean synthesizer or a production coverage benchmark. Passing
finite observations is not presented as a universal correctness proof. The
first candidate already passes this small append test corpus, so the recorded
CEGIS trace does not demonstrate a counterexample-driven speedup.

## Scope of the design

The proposed full system keeps native Lean `Expr`, universes, contexts, and
branch-local metavariables; its serializable layer contains control and replay
plans, not a Haskell-shaped type language. Major sections specify correlated
search, dependent cases, polymorphic provider instantiation, recursion carriers,
certificate algebras, CEGIS, typed SMT sketches, completion-wide certified
pruning, reversible observational parking, fair scheduling, exact cache keys,
and original-statement kernel validation.

Global library indexing, automatic recursion discovery, the fair production
scheduler, SMT integration, domain-certificate plugins, persistent workers,
and the publication service are designed but not implemented in this archive.
