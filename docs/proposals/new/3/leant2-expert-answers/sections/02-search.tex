\section{R1: search control with coupled goals}
\label{sec:search}

\Q{R1.1}{Can coupled goals be organized without wholesale copying or sequentialization?}
\ans Yes, in the useful sense of sharing persistent state and exploiting certified independence. No representation removes the underlying combinatorial alternatives when the constraints genuinely couple the goals. The right unit of independence is a \emph{constraint component}, not a goal name.

Aesop is a relevant existing implementation of best-first Lean proof search with dependent subgoals; its handling of shared metavariables is one reason a conventional independent AND/OR tree is insufficient \cite{aesop}. For Leant2, retain a joint branch state but factor its constraint graph whenever a sound dependency analysis permits it.

A state should contain a persistent metavariable snapshot, open goals, delayed constraints, observations, and an immutable environment identity. For each goal or observation, compute a conservative support: all unassigned expression and universe metavariables reachable through its expression, their types, local declarations and local values, and delayed assignments. Instance-search dependencies belong in that closure as well. Two targets containing no visibly shared metavariable may still be coupled through the type of a local or a universe constraint.

Build a hypergraph whose vertices are unresolved metavariables and whose hyperedges are obligations or constraints. Connected components can be scheduled separately only when the applicable rules are also \emph{effect-confined}: they may write component-local metavariables and fresh component-local variables, but may not silently connect components through a global mutable constraint. A new cross-component constraint merges components. In a persistent representation, merging need not copy all their old terms.

\begin{proposition}[A sufficient factorization criterion]
Suppose a search state partitions into components $S_1,\ldots,S_k$ with disjoint writable metavariable sets. Assume their constraints factor as a conjunction, all shared inputs are immutable, and every local transition and completion respects this partition. Then compatible satisfying substitutions for the components can be combined, and local search order does not change the set of combined solutions.
\end{proposition}
\begin{proof}
Each component substitution acts on a disjoint domain and does not introduce references to another component's writable variables. The substitutions therefore commute. Each conjunct depends only on its own substitution and immutable inputs, so it remains satisfied after the other substitutions are applied. Conversely, restricting any global satisfying substitution to the component domains yields satisfying component substitutions. This proves the correspondence. The effect-confinement assumption is essential: initial disjointness alone does not constrain what a later tactic may write.
\end{proof}

\textbf{Memoization.} First memoize \emph{closed, contextual solutions}, not arbitrary open solver states. Abstract a solution over precisely its used local telescope, canonicalize binder identities, record the environment and transparency regime, and recheck its instantiation at the reuse site. A proof of $P(x)$ is not a proof of $P(y)$ merely because its printed target looks similar. For open solutions, a cache entry must include interface substitutions and residual constraints; keeping only the first returned term can lose the only globally compatible solution.

The general implementation is a persistent search DAG with explicit component interfaces. A conservative first implementation can share only closed lemmas and keep the existing continuation discipline inside each connected component. This offers most of the correctness benefit without first building a full concurrent constraint solver. Measure retained memory as well as save/restore time: a cheap snapshot operation does not imply that retaining a large frontier is cheap.

\Q{R1.2}{What admissible heuristic survives shared metavariables?}
\ans Start with $h(s)=0$. Add only lower bounds proved by a cost-preserving relaxation. The proposed ``one unit per open non-leaf goal'' is not admissible under the proposal's own zero-cost exact rule, and coupling creates a second independent problem.

For example, suppose two open obligations can both be closed by assigning one shared metavariable to a local witness. If that assignment costs one, the true remaining cost is one, not two. Even without sharing, an exact-local step assigned cost zero defeats a positive unit lower bound.

Let $h_i(s)$ be a lower bound on the cost of satisfying obligation $i$ when the other obligations are relaxed. Then
\[
  h_{\max}(s)=\max_i h_i(s)
\]
is admissible: any full completion must also solve each relaxed problem. A sum is justified only across independent components whose future costs are charged disjointly. Independence of formulas alone is insufficient if a single charged production or shared subterm serves several components.

A stronger principled construction uses an abstraction $\alpha$ from concrete states to a finite relaxed state space. Require every concrete transition $s\to s'$ of cost $c$ to have an abstract path from $\alpha(s)$ to $\alpha(s')$ of cost at most $c$, and require concrete solutions to map to abstract solutions. The shortest abstract completion cost is then a lower bound.

\begin{proposition}[Abstract-distance heuristic]
Under those simulation assumptions, $h(s)=d_{\mathrm{abs}}(\alpha(s),\mathrm{Solved})$ is admissible.
\end{proposition}
\begin{proof}
Map any concrete completion path to the concatenation of its simulating abstract paths. The latter reaches an abstract solved state at no larger cost. The shortest abstract path is no more expensive than this one. Taking the infimum over concrete completions proves the claim.
\end{proof}

A type-head hypergraph, a small pattern database of constructor obligations, or a fractional covering relaxation can instantiate this construction, provided the simulation is actually proved for all productions. A fractional covering bound, for example, must permit one action to cover every obligation it can solve by unification. Forgetting those joint effects makes the relaxation an overestimate instead of a lower bound.

Use nonnegative fixed production costs. Give every genuinely generative cycle positive cost, or normalize its zero-cost closure finitely before queue insertion. Otherwise an infinite sequence of zero-cost expansions can starve a finite-cost solution. With an inconsistent heuristic, allow reopening states; alternatively retain a simpler uniform-cost baseline until measurements justify the added complexity.

\Q{R1.3}{Does just-in-time learning preserve meaningful ranking?}
\ans It preserves acceptance correctness when it only proposes terms, but it generally changes the candidates found before a deadline. That is a normal consequence of adaptive search, not a kernel issue. Probe supplies a published example of learning a probabilistic grammar from partial successes during enumeration; it does not establish that a finite-time candidate list is invariant under such updates \cite{probe}.

Separate two numbers:
\[
  c(p)=\text{fixed advertised ranking cost},\qquad
  q(s,t)=\text{possibly adaptive expansion priority}.
\]
A surviving observation can improve $q$ without rewriting the meaning of $c$. Record the policy version, observations used for updates, and tie-breaking rule. Freeze learned priorities within logical epochs; updates take effect at a specified event boundary. Rebuild or correctly rekey the queue when priorities change. Quietly leaving stale keys in a heap gives neither the intended adaptive order nor a reliable reproducibility story.

Maintain a fair baseline lane with a fixed grammar and cost order. If an optimality certificate is desired, its frontier lower bound must cover \emph{all} unexplored candidates in the advertised grammar, including those diverted to heuristic lanes. Heuristic search can find an excellent incumbent early; a separate certification frontier establishes when no better candidate remains.

Learning only reorders a finite bounded grammar if proposals actually belong to that grammar. A new helper type outside the bound is an extension, not a permutation. Record the extension explicitly, and never report exhaustion of the original grammar as exhaustion of the enlarged language. This distinction reappears in R9.

\Q{R1.4}{Can a wall-clock search be machine-speed independent?}
\ans Not in the strong form proposed, for an arbitrary adaptive search that returns everything it has discovered by a hard deadline. One can obtain deterministic \emph{logical prefixes}, deterministic completed batches, or replay of a recorded run. One cannot generally obtain the same useful discovered set at the same wall time on arbitrarily different machines.

\begin{proposition}[A wall-clock obstruction]
Consider a deterministic search with a candidate first discovered at logical event $j$. Suppose event $j$ finishes before deadline $D$ on one machine and after $D$ on another. A policy returning every candidate discovered by $D$ returns different sets on those machines.
\end{proposition}
\begin{proof}
The first run includes the candidate and the second run has not discovered it. Sorting the results does not add a missing candidate. The contradiction disappears only by changing the return policy, the resource definition, or the deadline guarantee.
\end{proof}

This elementary obstruction does not rule out valuable deterministic interfaces. Use a machine-independent logical work budget for canonical runs and expose a wall-clock cancellation mechanism. A cancellation returns the last completed logical checkpoint, together with an explicit incomplete status. The slower run may return an earlier checkpoint; resuming both to the same checkpoint must give the same candidate stream. Alternatively, reserve conservative fixed work tranches for a known machine class, accepting that an unusually slow machine may not complete the tranche.

For parallel search, assign jobs deterministic identities, allocate logical resources deterministically, and merge completed epochs in a fixed order. A race to the first result followed by cancellation is not deterministic even if the final sort is stable. Startup calibration improves throughput but does not remove cache effects, load variation, or exceptional expensive reductions.

Universal restart results such as Luby--Sinclair--Zuckerman concern specified models of Las Vegas runtimes. They should not be quoted as an optimality theorem for arbitrary deterministic lanes with correlated goals and reusable state \cite{luby}. Leant2's safer default is a deterministic, resumable portfolio, with measured scheduling improvements evaluated against that baseline.
