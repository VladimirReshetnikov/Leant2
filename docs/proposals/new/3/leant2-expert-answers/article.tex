\begin{abstract}
This report answers the expert questions in Leant2's September 2026 improvement plan and converts them into a staged architecture. Several uncertainties have useful published answers: Smyth supports higher-order examples and does not require trace-complete examples; Hoogle+ explicitly treats type classes by dictionary translation; Canonical demonstrates indexed recursion and generalized induction; AutoLifter addresses auxiliary-state synthesis; and container-based realizability analysis gives a principled starting point for polymorphic observations. Other questions require more carefully delimited guarantees. We separate correctness of accepted programs, preservation of solutions during pruning, bounded completeness, ranking optimality, and reproducibility. We give a constraint-component search model, admissible cost bounds, a sound finite-carrier exclusion test, typed and versioned observation caches, a conservative path to evaluation with holes, bounded motive enumeration, and a proof-producing realization interface for recursion. Counterexamples correct several tempting inferences: reverse is an ordinary fold into lists, the number of open goals is not an admissible general heuristic, and sorting concurrent results does not make a wall-clock search machine-independent. The final sections specify integration points, validation obligations, and an experimental plan without inventing speedups or model-accuracy figures.
\end{abstract}
